# Utopia Turistforening – APP2000

En responsiv low-fidelity-prototype for en turapp, laget i ren HTML og CSS.

## Kjør lokalt

Åpne `index.html` direkte i nettleseren, eller start en enkel lokal server:

```sh
python3 -m http.server 8000
```

Åpne deretter `http://localhost:8000`.

Prototypen demonstrerer tursøk, turtyper, turforslag, medlemskap og sosial chat.
Skjemaene lagrer ikke data, og løsningen har ingen JavaScript, backend eller database.
